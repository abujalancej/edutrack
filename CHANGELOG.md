# Changelog

## 1.3.0 — 2026-10-09

- Full backups and restore for teacher and tutor work, with a preview and an automatic recovery copy before replacing current data.
- Polished backup controls with localized labels, equal-width buttons and a restore summary.
- Automatic chronological ordering of assessments in worksheets, imported submissions and new reports. Undated assessments appear last.
- Localized class PDF filenames, file dialog filters and worksheet copy messages.
- Class PDFs pad each student's report to an even page count for duplex printing.
- The latest tracking report can be deleted even after its PDFs have been generated.
- Removed the default Electron application menu.
- Application and generated PDF footers display version 1.3.0.

## 1.2.0 — 2026-10-07

- Individual assessments for selected students, counted as exams or continuous assessment. They are omitted from other students’ reports and preserved when copying, exporting and importing worksheets.
- Spreadsheet selection, keyboard navigation and Excel paste for grades, assessment observations and tutor observations. Tutor comments support quoted multiline Excel cells.
- Direct entry of configured letter grades without a dropdown.
- Compact student selection in the assessment dialog.
- Centered green and gold loading indicator with a blurred background during report generation.
- Excluded subjects use a yellow status icon. Subject cards have a uniform, compact height.
- Imported teacher submissions show the file’s generation date and time, with localized labels and separate lines for the teacher and date.
- Application and generated PDF footers display version 1.2.0.
